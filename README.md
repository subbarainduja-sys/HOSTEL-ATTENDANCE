## 📌 Project Overview

The **Hostel Attendance System** is a smartphone-first web application designed for hostel attendance management. It replaces manual paper registers with **real machine-readable QR code session verification** and **front-camera photo capture verification**.

---

## 🛠️ Real QR Code & Scanner Architecture

### 1. Real Machine-Readable QR Code Generator (Admin)
- **Library Used:** `lib/qrcode.min.js` (Standard Davidshimjs ISO/IEC 18004 QR Generator Engine).
- **QR Payload Format:** Real structured JSON containing session metadata:
  ```json
  {
    "type": "HOSTEL_ATTENDANCE",
    "sessionId": "SESS_1728059000123",
    "hostelBlock": "A Block",
    "date": "2026-10-04",
    "createdAt": "08:00 AM",
    "validUntil": "11:59 PM"
  }
  ```
- Generates a high-resolution machine-readable QR code on Canvas/SVG that any smartphone camera (iPhone Camera App, Android Google Lens, or `jsQR`) can scan and decode.

### 2. Real Camera QR Scanner (Student)
- **Scanner Library Used:** `lib/jsqr.js` (Official production-grade `jsQR` decoding engine).
- Accesses smartphone camera feed via `navigator.mediaDevices.getUserMedia({ video: { facingMode: 'environment' } })`.
- Continuously decodes video frames, parses JSON payloads, and validates `type === "HOSTEL_ATTENDANCE"`.
- Features real-time detection feedback (`✓ QR Code Detected`, `✓ Attendance Session Verified`).
- Handles invalid QR codes ("Invalid QR Code - Please scan the Hostel Attendance QR generated by administration") and expired QR codes.

## 📱 How to Test on a Mobile Smartphone & Camera Security Requirements

### Browser Camera Security Rules (Important for Smartphone Demo):
Modern mobile browsers (iOS Safari and Android Chrome) restrict camera access (`navigator.mediaDevices.getUserMedia`) to **Secure Origins**:
- **`http://localhost:8000`** or **`http://127.0.0.1:8000`** (Always allowed on desktop/laptop).
- **`https://`** (Allowed everywhere).

### Testing Options on a Mobile Phone:

1. **Option A: Testing on Desktop/Laptop Webcam (Easiest for Review)**:
   - Open two browser windows at `http://localhost:8000`:
     - Window 1: Admin Dashboard (Displaying the active generated QR).
     - Window 2: Student Login -> Click **Scan QR Code**.
   - Point your webcam at Window 1 or display the Admin QR on a phone screen in front of the webcam.
   - The `jsQR` engine will scan, decode, and verify the session instantly!

2. **Option B: Testing on Mobile Phone over Local Wi-Fi**:
   - Find your laptop's local IP (e.g. `192.168.1.50` using `ipconfig`).
   - Open Android Chrome on your phone and navigate to `chrome://flags/#unsafely-treat-insecure-origin-as-secure`.
   - Add `http://192.168.1.50:8000` to the enabled list and relaunch Chrome.
   - Now Chrome on your phone will grant full camera access to scan the Admin QR code on the laptop screen!

3. **Option C: Using Demo QR Fallback**:
   - If camera permissions are unavailable during review, click **Use Demo QR Verification** to demonstrate the complete workflow smoothly.
